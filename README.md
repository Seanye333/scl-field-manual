# SCL Field Manual

A practical, single-page course in Structured Control Language (SCL) for Siemens TIA Portal, targeting S7-1200/1500 PLCs.

**Live site:** https://seanye333.github.io/scl-field-manual/

- **24 chapters** — from a first function block through state machines, closed-loop control, communications, interrupt design, program architecture, and a two-part pattern cookbook (valve, analog channel, alarm manager, duty/standby, pause/step-mode sequences, ring-buffer logger).
- **The Playground** — an in-browser SCL scan-cycle simulator with **6 graded labs** on animated machines — a train with a level crossing, and single- and dual-pump tanks with a mid-run pump failure.
- **Quizzes in every core chapter** plus a scored 20-question final exam.
- **Exercises with fold-out solutions**, a printable quick-reference card, full-text search, a light/dark theme toggle, and per-chapter progress tracking (stored locally in the browser).
- **`src/`** — every block from the manual as TIA-importable external source files (see `src/README.md`).

Open `index.html` directly, or view the published page above.
