# SCL Field Manual

A practical, single-page course in Structured Control Language (SCL) for Siemens TIA Portal, targeting S7-1200/1500 PLCs.

18 chapters covering the language from first function block to state machines, closed-loop control, and communications — with self-check quizzes, exercises with fold-out solutions, a quick-reference card, and per-chapter progress tracking (stored locally in the browser).

Open `index.html` directly, or view the published page via GitHub Pages.
